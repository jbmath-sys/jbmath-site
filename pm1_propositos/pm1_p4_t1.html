PM I · Propósito 1

Unidad y números racionales como fracciones

Comprender cómo una unidad puede dividirse en partes iguales para representar números racionales.

← Tema anterior Siguiente tema →

1) ¿Qué es una unidad?

Una unidad es una cantidad completa que tomamos como referencia para medir o comparar.

Ejemplos de unidad:
  • Una pizza completa
  • Un metro
  • Un litro
  • Un pastel entero

Cuando dividimos una unidad en partes iguales, cada parte puede representarse con una fracción.

2) ¿Qué es un número racional?

Un número racional es cualquier número que puede escribirse como una fracción.

Forma general: a / b

donde:
  • a = numerador
  • b = denominador
  • b ≠ 0

3) Estructura de una fracción

Numerador

Indica cuántas partes se toman de la unidad.

Ejemplo: 3/4 → se toman 3 partes.

Denominador

Indica en cuántas partes iguales se divide la unidad.

Ejemplo: 3/4 → la unidad se divide en 4 partes.

4) Ejemplos de números racionales

  • 1/2
  • 3/4
  • 5/3
  • 7/10

Todos estos números representan partes de una unidad.

5) Interpretación visual

Si una pizza se divide en 8 partes: 3/8 significa que tomamos 3 de esas 8 partes.

Escribe un numerador y denominador para interpretar la fracción.
